# 💰 Sistema de Gestión de Gastos del Hogar

Aplicación web fullstack para el control de gastos e ingresos del hogar, con análisis y visualización de datos.

---

## 🚀 Funcionalidades

- Registro e inicio de sesión de usuarios
- Registro de gastos por categoría
- Visualización del historial de gastos
- Filtros por día, semana y mes
- Dashboard con gráficos de consumo
- Definición de presupuestos por categoría
- Recomendaciones inteligentes
- Registro de ingresos
- Balance financiero en tiempo real

---

## 🧠 Tecnologías usadas

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

### Backend
- Java (Spring Boot)
- REST API

### Base de datos
- PostgreSQL (Neon)

### Deploy
- Frontend → GitHub Pages (GitHub Actions)
- Backend → Render
- Base de datos → Neon
